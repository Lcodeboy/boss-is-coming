# 按钮音色候选试听

这组资源用于选择《老板要来了》的交互声音方向，不自动替换正式按钮音，不进入 Cocos 资源包。全部由固定参数的衰减正弦共鸣和固定种子滤波噪声生成，没有外部采样或第三方依赖。

当前已选定并接入 **C 圆润电子轻点**。正式与候选脚本共用 `button-voice.mjs`，无需复制试听文件。正式生成运行 `node tools/generate-feedback-audio.mjs`；选定音色一致性回归运行 `node tests/button-audio-regressions.mjs`。候选生成命令仍只写入试听目录，不覆盖正式资源。

## 生成与检查

在仓库根目录执行：

```sh
node tools/generate-button-candidates.mjs
node tools/generate-button-candidates.mjs --check
```

输出目录：`artifacts/button-audio/`。单声道、22,050Hz、16-bit PCM WAV。`--check` 校验资源逐字节可复现、三种音色不同、格式/时长/端点/峰值/静音/DC偏置及平均响度匹配。

| 文件 | 声音方向 | 时长 | 设计特点 |
| --- | --- | --- | --- |
| a-soft-mechanical.wav | A 柔和机械扣 | 160ms | 短促滤波敲击＋非整数倍共鸣，模拟温暖的小机械扣 |
| b-paper-wood.wav | B 纸木轻敲 | 170ms | 较低共鸣＋更长的滤波摩擦，偏办公室纸木材质 |
| c-rounded-electronic.wav | C 圆润电子轻点（已选定） | 165ms | 平稳圆润的音高、柔和起音、弱泛音，无噪声 |
| abc-comparison.wav | 连续对比 | 约5.6秒 | A三次→B三次→C三次，组内间隔0.4秒，组间间隔0.85秒 |

三种声音匹配平均响度（RMS目标0.050、峰值上限0.30），但测量接近不保证主观响度相同。短音效听感还受手机扬声器和音色影响，需要在同一设备、同一音量下比较。连播内静音是有意留出的试听间隔，正式候选自身没有长静音。

## 试听顺序

1. 先用同一设备中低音量播放 `abc-comparison.wav`，比较材质与起音，不因为某种声音听起来更响就优先选它。
2. 单独播放最喜欢的候选，判断是否还尖锐、是否太短、有没有拖尾。
3. 手机外放再听一遍，兼顾能听清和不抢注意力；耳机只能作为补充。
4. 已接入 C；在游戏连续点击、正确拖放、消息和警示同时出现时复测。游戏主音量仍为0.65，独立试听文件未经该主音量衰减。

当前只替换按钮资源，不改音效 ID、播放优先级、限频、生命周期、关卡配置或业务逻辑。没有增加背景音乐或环境音，不推广到其他11种音效，不自动提交 Git。
